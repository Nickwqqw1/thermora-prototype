# THERMORA — интерактивен прототип

Три раздела на болгарском: Начало, Енергиен анализ, Решения. Статический HTML/CSS/JavaScript. Все изображения и шрифты сохранены локально. Данные форм остаются в браузере, сервер и регистрация не нужны.

## Как открыть

Откройте index.html двойным щелчком. Для просмотра через локальный сервер откройте терминал в этой папке и запустите:

    python -m http.server 8765 --bind 127.0.0.1

Затем откройте http://127.0.0.1:8765 . Этот адрес работает только на данном компьютере. Для iPhone и друзей используйте опубликованный HTTPS-адрес.

## Бесплатная публикация на GitHub Pages

Публичный репозиторий и публикация требуют подтверждения владельца. Подготовлен .github/workflows/pages.yml.

1. Создайте публичный репозиторий thermora-prototype.
2. Загрузите index.html, styles.css, app.js, assets/, .nojekyll, README.md и .github/workflows/pages.yml в корень ветки main. Не загружайте скриншоты проверки.
3. В Settings → Pages выберите Source: GitHub Actions.
4. Запустите workflow Publish THERMORA в Actions, если он ещё не стартовал.
5. После успешного выполнения откройте https://ВАШ-ЛОГИН.github.io/thermora-prototype/ . Проверьте навигацию и все три калькулятора на компьютере и iPhone.

Альтернатива без workflow: Settings → Pages → Deploy from a branch → main / (root).

Опубликовано: https://nickwqqw1.github.io/thermora-prototype/ . 10 октября 2026 года проверены открытие публичного HTTPS-адреса, навигация и все три калькулятора в браузере. Это не проверка на физическом iPhone.

## Расчёты и ограничения

Отопление: месячный расход × месяцы = расход за сезон. Деление на площадь даёт €/m² за сезон, не энергоэффективность и не класс здания. Город не превращается в выдуманный климатический коэффициент.

Пол: площадь × W/m² / 1000 = kW. Умножение на часы = kWh при постоянной мощности. Электрический пол: теоретическое потребление при заданном режиме. Водный: тепловая энергия, не расход электричества источником.

Солнечная система: kWp × заданный kWh/kWp = годовая генерация. Генерация × доля собственного потребления × тариф = ориентировочный избегнутый расход. Экспорт, батереи, обслуживание, инвестиции и окупаемость не моделируются. Начальные 1300 kWh/kWp и 0,15 €/kWh — демонстрационные допущения.

Поля имеют ограничения; при изменении данных старый результат сбрасывается. Есть текстовый просмотр результата для копирования. Это прототип для обсуждения, не инженерные рекомендации.

## Перенос на WordPress

Разделить разметку на header.php, footer.php и шаблоны трёх страниц; подключить стили и JavaScript через enqueue; перевести тексты и изображения в редактируемые поля/блоки; заменить hash-навигацию реальными URL; добавить серверную валидацию только если потребуется сохранять или отправлять заявки; настроить хостинг, безопасность, резервные копии и политику обработки данных. Инженерную модель разрабатывать и проверять отдельно со специалистом.

## Проверки

Проверены расчёты 500 €/сезон; 1,2 kW и 7,2 kWh для обеих систем пола; 6500 kWh/год., собственное потребление 3900 kWh и 585 €/год.; нулевое собственное потребление даёт нулевую экономию. Проверены мобильное меню, фильтры и окно подробностей. Проверка размера iPhone 15 Pro выполнялась в браузерном viewport 393 × 852; это не тест на физическом iPhone или Safari.
